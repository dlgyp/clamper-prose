# Instructions for AI Writing Assistants

This repository contains an **unofficial, public** literary style guide for Clamper Prose. Read [STYLE_GUIDE.md](STYLE_GUIDE.md), [AI_USAGE.md](AI_USAGE.md), and [EXAMPLES.md](EXAMPLES.md) before preparing writing in this style.

## Working rules

1. **Use Clamper Prose only when explicitly requested.** Do not apply it to unrelated correspondence or technical tasks.
2. **Clarify before drafting when needed.** Determine the intended audience, genre, purpose, delivery medium, and essential logistics. Ask a few targeted questions about missing information that materially affects the draft; do not ask for facts already supplied. If the request is complete, draft immediately. If the user requests a quick concept, use clearly labeled placeholders rather than inventing facts.
3. **Match the genre.** A personal thank-you, historical feature, reminder, and proclamation should not sound identical. Mock-legalese belongs chiefly in actual proclamations.
4. **Keep essential details clear.** Make what, when, where, why, cost, deadline, and action easy to find. Use emphasis for useful skimmable information, not decoration.
5. **Check factual completeness before delivery.** Compare the draft with all user-supplied details. Preserve every material fact, including prices, refreshments, eligibility, RSVP instructions, and unusual scheduling. Never replace known information with placeholders. Flag only genuinely missing information; do not invent venue history, chapter practices, or specific memorial activities. Ensure the logistics can be understood without reading the satire.\n6. **Balance the literary influences.** Pair extravagant frontier pomposity with dry, observant, Twain-like wit. Avoid stock archaic openings and empty verbosity.
7. **Verify factual assertions.** Do not invent historical facts, event details, offices, chapter customs, eligibility rules, or citations. Do not disclose confidential ceremonies or private chapter information.
8. **Be responsible and respectful.** Affectionate mockery is welcome; cruelty, coercion, dangerous conduct, and glorification of intoxication are not. Where alcohol is mentioned in event notices, convey responsible consumption.
9. **Respect local context.** This public repository is chapter-neutral. If a user supplies private chapter guidance, apply it only in that authorized context and do not copy it into this public repository.
10. **Request human review before publication.** Check all dates, prices, links, names, and attendance restrictions.

## Repository boundaries

This repository is public and intentionally generalized. Do **not** import private chapter documents or personal details into issues, pull requests, or commits. Proposed additions should be broadly useful, accurate, and safe to publish.

The guide is unofficial; it is not an authoritative statement of E Clampus Vitus doctrine, bylaws, or practices.
